# GRAFT 요구사항 명세서

- 문서 버전: 0.1 (2026-09-16, 초기 브레인스토밍 정리)
- 장르: 사이버펑크 갱단 경영 시뮬레이션 + 로그라이트
- 플랫폼: 데스크톱 웹 브라우저 우선, 모바일 가로 모드는 2차 목표
- 비주얼 레퍼런스: VA-11 Hall-A 계열의 저해상도 픽셀 아트, 제한된 팔레트, 비 내리는 네온 도시, 작은 스프라이트와 디테일한 초상화의 대비

---

## 1. 제품 비전

비 내리는 수직 도시의 밑바닥에서 작은 갱단을 이끌고 도시를 장악해 나가는 게임. 대사 위주의 스토리 대신 **경영 결정과 짧은 이벤트 카드**로 드라마를 만든다. 한 판(런)은 30~60분, 한 턴(하룻밤)은 1~2분 안에 끝나 웹에서 가볍게 반복 플레이할 수 있어야 한다.

### 핵심 재미 (디자인 필러)

1. **욕심과 위험의 저울질:** 돈이 되는 행동일수록 열기가 오른다.
2. **사람에 대한 애착:** 조직원은 각자 특성·충성도·인간성을 가진 인물이며 영구적으로 잃을 수 있다.
3. **변하는 도시:** 내 영향력이 지도와 거리 풍경에 눈에 보이게 반영된다.
4. **짧고 반복 가능한 런:** 실패해도 유산이 남아 다음 런이 조금 달라진다.

## 2. 용어 정의

| 용어 | 정의 |
|---|---|
| 런(Run) | 새 게임 시작부터 승리 또는 패배까지의 한 판 |
| 밤(Night) | 1턴. 계획 → 실행 → 결산 → 성장 단계로 구성 |
| 구역(District) | 도시 지도의 점령 단위 |
| 열기(Heat) | 경찰·기업의 주목도. 0~100 |
| 인간성(Humanity) | 조직원별 수치. 사이버웨어 이식으로 감소 |
| 유산(Legacy) | 런 종료 시 획득해 다음 런에 쓰는 메타 재화 |

## 3. 기능 요구사항

우선순위: **P0** = MVP 필수, **P1** = MVP 이후 1차, **P2** = 여유 시

### 3.1 런 구조

- **FR-RUN-01 (P0)** 새 런 시작 시 시드를 생성하고, 시드와 선택한 유산 보너스로 초기 상태를 만든다. 시드는 결과 화면에 표시한다.
- **FR-RUN-02 (P0)** 런은 최대 30밤으로 진행된다.
- **FR-RUN-03 (P0)** 승리 조건: 기업 지구를 장악한 상태로 밤을 마치거나, 두 경쟁 갱단을 모두 괴멸시킨다.
- **FR-RUN-04 (P0)** 패배 조건 중 하나라도 충족하면 런이 끝난다: 보스 사망, 크레딧이 3밤 연속 음수, 30밤 종료 시 승리 조건 미달성, 급습으로 은신처 함락.
- **FR-RUN-05 (P0)** 런 종료 화면에 생존 밤 수, 최대 장악 구역 수, 잃은 조직원, 획득 유산을 표시한다.

### 3.2 턴(밤) 루프

- **FR-TURN-01 (P0)** 한 밤은 다음 4단계를 순서대로 진행한다.
  1. 해질녘(계획): 조직원 배치
  2. 밤(실행): 행동 해결, 이벤트 발생
  3. 새벽(결산): 수입·피해·열기 변화 보고
  4. 낮(성장): 영입, 사이버웨어 이식, 사업 건설·업그레이드
- **FR-TURN-02 (P0)** 실행 단계는 자동 진행하되, 이벤트 발생 시 일시 정지하고 이벤트 카드를 띄운다.
- **FR-TURN-03 (P0)** 각 밤이 끝날 때 자동 저장한다.

### 3.3 자원

- **FR-RES-01 (P0)** 크레딧: 수입과 지출의 기본 재화. 매 새벽 유지비(조직원 급여 + 사업 유지비)가 차감된다.
- **FR-RES-02 (P0)** 열기: 0~100 전역 수치. 행동에 따라 증가하고, 조용한 밤에는 자연 감소한다.
- **FR-RES-03 (P0)** 평판: 0~100. 영입 가능한 조직원의 등급과 보호비 수입에 영향을 준다.
- **FR-RES-04 (P1)** 부품: 사이버웨어 제작·수리 재료.

### 3.4 도시 지도와 구역

- **FR-MAP-01 (P0)** MVP 지도는 3개 층, 6개 구역으로 구성한다.

  | 층 | 구역 | 성격 |
  |---|---|---|
  | 하층 | 슬럼 | 시작 구역. 저수익, 저열기, 방어 약함 |
  | 하층 | 항만 | 밀수 보너스. 중수익 |
  | 하층 | 지하 시장 | 사이버웨어 할인. 경쟁 갱 A 시작 지점 |
  | 중층 | 유흥가 | 격투장·밀매 고수익. 경쟁 갱 B 시작 지점 |
  | 중층 | 공장 지대 | 부품 산출. 방어 강함 |
  | 상층 | 기업 지구 | 최고 수익, 열기 배수 2배. 최종 목표 |

- **FR-MAP-02 (P0)** 구역은 소유자(플레이어/경쟁 갱 A/경쟁 갱 B/중립), 방어력, 사업 슬롯 수, 수입 배수, 열기 배수, 인접 구역 목록을 가진다.
- **FR-MAP-03 (P0)** 공격은 내가 소유한 구역과 인접한 구역에만 할 수 있다. 상층은 중층 구역을 1개 이상 소유해야 공격 가능하다.
- **FR-MAP-04 (P0)** 정찰하지 않은 적 구역은 방어력과 사업 정보가 가려진다(전장의 안개).
- **FR-MAP-05 (P1)** 구역 장악 시 해당 구역의 지도 아이콘과 거리 뷰 장식(그래피티, 간판 색)이 플레이어 갱 테마로 바뀐다.

### 3.5 사업

- **FR-BIZ-01 (P0)** MVP 사업 4종.

  | 사업 | 수익 | 열기 | 요구 능력 | 부가 효과 |
  |---|---|---|---|---|
  | 보호비 징수 | 낮음 | 낮음 | 무력 | 평판에 비례해 수입 증가 |
  | 사이버웨어 시술소 | 중간 | 중간 | 기술 | 이식 비용 할인 |
  | 지하 격투장 | 중간 | 중간 | 무력 | 평판 상승 |
  | 데이터 밀매 | 높음 | 높음 | 기술 | 해커 배치 필수 |

- **FR-BIZ-02 (P0)** 사업은 구역 슬롯에 건설하며 레벨 1~3 업그레이드가 가능하다.
- **FR-BIZ-03 (P0)** 조직원을 운영에 배치해야 수입이 발생하며, 배치 조직원의 해당 능력치가 수입에 반영된다.
- **FR-BIZ-04 (P1)** 위장용 바: 수익은 낮지만 매 밤 열기를 감소시킨다.

### 3.6 조직원

- **FR-CREW-01 (P0)** 조직원 속성: 이름, 초상화 키, 능력치 4종(무력/기술/교섭/은신, 각 1~10), 인간성(0~100), 충성도(0~100), 특성 1~2개, 급여, 상태(정상/부상/체포/사망), 장착 사이버웨어 목록.
- **FR-CREW-02 (P0)** 런 시작 시 보스 1명 + 조직원 2명. 영입 풀은 데이터로 정의된 최소 12명.
- **FR-CREW-03 (P0)** 각 조직원은 한 밤에 한 가지 행동만 한다: 사업 운영, 구역 공격, 구역 방어, 정찰, 휴식(부상 회복·인간성 소폭 회복).
- **FR-CREW-04 (P0)** 부상은 N밤 동안 행동 불가, 사망은 영구적이다. 보스는 사망 시 패배다.
- **FR-CREW-05 (P0)** 사이버웨어 이식: 능력치를 올리는 대신 인간성이 감소한다. 인간성 20 미만이면 매 밤 폭주 이벤트 확률이 생긴다.
- **FR-CREW-06 (P0)** 충성도는 급여 체불, 위험 임무 연속 배치, 동료 사망 시 감소하고, 휴식·보상 이벤트로 증가한다. 30 미만이면 이탈 또는 배신(적에게 정보 누출) 이벤트 확률이 생긴다.
- **FR-CREW-07 (P1)** 조직원 간 관계(친분/불화)가 함께 배치 시 성공률에 영향을 준다.

### 3.7 행동 해결

- **FR-ACT-01 (P0)** 성공 확률 = 배치 조직원 관련 능력치 합 대비 대상 난이도의 함수. 수치 공식은 데이터 파일의 계수로 조정 가능해야 한다.
- **FR-ACT-02 (P0)** 결과 등급은 대성공/성공/실패/대실패 4단계이며, 대실패 시 부상·체포 위험이 있다.
- **FR-ACT-03 (P0)** 결산 화면에서 각 행동의 성공 확률과 실제 결과를 확인할 수 있어야 한다(결과의 이유를 플레이어가 이해할 수 있도록).

### 3.8 열기

- **FR-HEAT-01 (P0)** 열기 구간별 효과.

  | 구간 | 효과 |
  |---|---|
  | 0~39 | 영향 없음. 조용한 밤이면 자연 감소 |
  | 40~69 | 경찰 단속 이벤트 확률 발생 (벌금, 체포) |
  | 70~99 | 기업 진압대 급습 확률 발생 (구역 방어전) |
  | 100 | 다음 밤 은신처 급습 확정 |

- **FR-HEAT-02 (P0)** 지도 화면에 열기 게이지를 항상 표시하고, 배치 확정 전에 예상 열기 증가량을 미리 보여준다.
- **FR-HEAT-03 (P1)** 뇌물(크레딧 소모)로 열기를 즉시 낮출 수 있다.

### 3.9 경쟁 갱단 AI

- **FR-AI-01 (P0)** 경쟁 갱 2개. 각자 성향이 다르다: A = 확장형(중립 구역 우선 점령), B = 공격형(가장 방어가 약한 플레이어 구역 공격).
- **FR-AI-02 (P0)** AI 행동은 플레이어 행동 해결 후, 같은 시드 RNG로 결정한다.
- **FR-AI-03 (P0)** 모든 구역을 잃은 경쟁 갱은 괴멸 처리한다.
- **FR-AI-04 (P1)** 경쟁 갱끼리도 서로 공격할 수 있다.

### 3.10 이벤트

- **FR-EVT-01 (P0)** 이벤트는 데이터 파일로 정의한 카드이며, 초상화, 짧은 본문(3문장 이하), 선택지 2~3개, 선택지별 효과로 구성된다.
- **FR-EVT-02 (P0)** 이벤트는 발생 조건(열기 구간, 특정 조직원 상태, 소유 구역 등)과 가중치를 가진다.
- **FR-EVT-03 (P0)** MVP 이벤트 최소 20종: 단속, 급습, 폭주, 배신, 이탈, 영입 제안, 거래 제안, 뇌물 요구 등.
- **FR-EVT-04 (P1)** 조직원별 개인 이벤트 체인(3단계)으로 인물의 사연을 조금씩 드러낸다.

### 3.11 메타 진행 (유산)

- **FR-LEG-01 (P0)** 런 종료 시 성과에 따라 유산 포인트를 지급한다.
- **FR-LEG-02 (P0)** 유산 포인트로 시작 보너스를 영구 해금한다. MVP 5종: 시작 크레딧 증가, 시작 조직원 추가, 시작 열기 감소, 사업 1종 선건설, 영입 풀에 특수 조직원 추가.
- **FR-LEG-03 (P0)** 유산 데이터는 런 저장과 분리해 보관하며 런을 삭제해도 유지된다.

### 3.12 화면

- **FR-UI-01 (P0)** 타이틀: 새 런, 이어하기, 유산, 설정.
- **FR-UI-02 (P0)** 은신처(홈): 측면 픽셀 뷰. 조직원 스프라이트가 대기하고, 창밖으로 비 내리는 도시가 보인다. 각 기능 화면으로 이동하는 허브.
- **FR-UI-03 (P0)** 도시 지도: 3개 층을 세로로 쌓은 구역 맵. 소유자 색, 열기 게이지, 크레딧, 현재 밤 번호 표시. 조직원 배치가 이 화면에서 이루어진다.
- **FR-UI-04 (P0)** 결산 리포트: 행동별 결과, 수입·지출, 열기 변화, 조직원 상태 변화.
- **FR-UI-05 (P0)** 이벤트 카드 모달.
- **FR-UI-06 (P0)** 조직원 목록/상세: 초상화 64×64, 능력치, 인간성·충성도 게이지, 사이버웨어 이식.
- **FR-UI-07 (P1)** 거리 뷰: 구역 선택 시 패럴랙스 스크롤 거리 풍경(원경 빌딩, 중경 간판, 근경 거리).
- **FR-UI-08 (P0)** UI는 주인공의 해킹 단말기 화면처럼 연출한다(스캔라인, 모노스페이스 픽셀 폰트, 팔레트 제한).

## 4. 비기능 요구사항

- **NFR-01 (P0)** 성능: 데스크톱 중급 사양에서 60fps 유지. 초기 로딩 3초 이내(에셋 캐시 전).
- **NFR-02 (P0)** 결정론: 같은 시드와 같은 입력 기록이면 같은 결과가 재현되어야 한다.
- **NFR-03 (P0)** 테스트: `src/core/` 전 시스템에 단위 테스트. 코어 로직 라인 커버리지 80% 이상.
- **NFR-04 (P0)** 밸런스 검증: 헤드리스 시뮬레이터로 규칙 기반 봇 1,000런을 실행해 승률, 평균 생존 밤, 패배 원인 분포를 출력할 수 있어야 한다.
- **NFR-05 (P0)** 저장: 스키마 버전을 포함하고, 구버전 저장 데이터는 마이그레이션하거나 안전하게 폐기 안내한다.
- **NFR-06 (P0)** 입력: 마우스 전용으로 전 기능 플레이 가능. 주요 동작에 키보드 단축키 제공.
- **NFR-07 (P1)** 모바일 가로 모드 터치 조작.
- **NFR-08 (P0)** 배포: 정적 파일 빌드로 GitHub Pages 등 정적 호스팅에 배포 가능.
- **NFR-09 (P0)** 폰트: 한글 지원 픽셀 폰트는 오픈 라이선스(예: OFL)만 사용하고 라이선스 파일을 저장소에 포함한다.
