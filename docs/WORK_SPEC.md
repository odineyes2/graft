# GRAFT 작업 명세서

- 문서 버전: 0.1 (2026-09-16)
- 기준 문서: `docs/REQUIREMENTS.md`
- 진행 규칙: `CLAUDE.md`의 "작업 방식" 참고. 작업 ID 순서대로 진행하되, 같은 마일스톤 안에서 의존성이 없는 작업은 순서를 바꿔도 된다.

각 작업은 **목표 / 산출물 / 완료 조건**으로 구성된다. 완료 조건을 모두 만족해야 체크한다.

## M0. 개발 환경

### [x] T-00 프로젝트 스캐폴딩
- **목표:** 빈 저장소를 실행 가능한 Phaser 4 + TypeScript + Vite 프로젝트로 만든다.
- **산출물:** `package.json`, Vite·TS·ESLint·Prettier·Vitest 설정, `CLAUDE.md`의 폴더 구조, 480×270 픽셀 아트 설정이 적용된 빈 부트 씬, `.gitignore`.
- **완료 조건:**
  - `npm run dev`로 브라우저에 480×270 캔버스가 정수 배율로 확대되어 표시된다.
  - `npm run build`, `npm run test`, `npm run lint`가 에러 없이 끝난다.
  - 설치한 Phaser·Vite·TypeScript·Vitest의 실제 버전을 `docs/DECISIONS.md`에 기록한다.

### [x] T-01 기술 버전 점검 기록
- **목표:** 사용하는 주요 라이브러리의 최신 안정 버전과 커뮤니티 사용 현황을 확인해 결정 근거를 남긴다.
- **산출물:** `docs/DECISIONS.md`의 "기술 스택" 섹션.
- **완료 조건:**
  - Phaser 4.x 최신 버전과 Phaser 3 대비 이 프로젝트에 영향 있는 API 차이(Filter 시스템, 렌더러, 텍스트 렌더링)를 정리한다.
  - Phaser 3 예제를 참고할 때 주의할 점을 3개 이상 적는다.

### [x] T-02 팔레트·폰트·임시 에셋 체계
- **목표:** 비주얼 규칙을 코드로 고정한다.
- **산출물:** `src/ui/palette.ts`(24~32색 토큰), 한글 픽셀 폰트 적용 및 라이선스 파일, `assets/ASSET_MANIFEST.md`, 임시 에셋 생성 유틸(단색 사각형·실루엣).
- **완료 조건:** 부트 씬에 팔레트 견본과 한글·영문·숫자 샘플 텍스트가 선명하게(블러 없이) 표시된다.

## M1. 코어 로직 (렌더링 없음, `src/core/`)

### [x] T-10 게임 상태 모델
- **목표:** 요구사항의 모든 P0 엔티티를 타입으로 정의한다.
- **산출물:** `src/core/types.ts` (RunState, District, Business, CrewMember, Cyberware, RivalGang, EventCard, Assignment, NightReport, LegacyState).
- **완료 조건:** 타입만으로 초기 런 상태 1개를 생성하는 테스트가 통과한다. Phaser·DOM 참조가 없다.

### [x] T-11 시드 RNG
- **산출물:** `src/core/rng.ts` (정수 범위, 실수, 가중치 선택, 셔플, 상태 직렬화).
- **완료 조건:** 같은 시드로 10,000회 호출한 결과가 항상 동일하다는 테스트, RNG 상태를 저장·복원한 뒤 이어지는 값이 동일하다는 테스트가 통과한다.

### [x] T-12 콘텐츠 데이터와 검증
- **목표:** MVP 콘텐츠를 JSON으로 작성하고 로드 시 검증한다.
- **산출물:** `src/data/` 아래 districts, businesses, crew, cyberware, rivals, events, legacy, balance JSON. 스키마 검증 코드.
- **완료 조건:**
  - REQUIREMENTS 6장의 수량을 모두 충족한다.
  - 존재하지 않는 구역 ID 참조, 비대칭 인접 관계, 선택지 없는 이벤트 등을 잡아내는 검증 테스트가 통과한다.

### [x] T-13 밤 해결 엔진
- **목표:** 배치 입력을 받아 한 밤을 해결하는 순수 함수를 만든다.
- **산출물:** `resolveNight(state, assignments, rng) => { state, report }`, 행동별 해결 모듈(운영/공격/방어/정찰/휴식).
- **완료 조건:**
  - FR-ACT-01~03, FR-CREW-03~04, FR-BIZ-03을 만족한다.
  - 리포트에 행동별 성공 확률과 결과 등급이 포함된다.
  - 같은 입력·시드면 같은 리포트가 나오는 테스트가 통과한다.

### [x] T-14 경제·유지비
- **완료 조건:** 새벽 결산에서 수입과 급여·유지비가 반영되고, 크레딧 음수 연속 밤 수가 추적된다(FR-RES-01, FR-RUN-04). 테스트 통과.

### [x] T-15 열기 시스템
- **완료 조건:** 행동별 열기 증가, 자연 감소, 구간별 이벤트 트리거 조건, 100 도달 시 급습 확정이 동작한다(FR-HEAT-01). 배치 확정 전 예상 열기 증가량을 계산하는 함수가 있다(FR-HEAT-02).

### [ ] T-16 조직원 상태 시스템
- **완료 조건:** 사이버웨어 이식에 따른 능력치·인간성 변화, 충성도 증감 규칙, 인간성 20 미만·충성도 30 미만 시 위험 이벤트 확률이 동작한다(FR-CREW-05~06).

### [ ] T-17 이벤트 시스템
- **완료 조건:** 조건 필터링 → 가중치 선택 → 선택지 효과 적용이 동작한다. 같은 밤에 같은 이벤트가 중복 발생하지 않는다(FR-EVT-01~03).

### [ ] T-18 경쟁 갱단 AI
- **완료 조건:** 두 성향(확장형/공격형)이 규칙대로 행동하고, 구역을 모두 잃으면 괴멸 처리된다(FR-AI-01~03).

### [ ] T-19 승패 판정과 런 종료 정산
- **완료 조건:** FR-RUN-03~05, FR-LEG-01의 조건별 테스트가 모두 통과한다.

### [ ] T-20 헤드리스 시뮬레이터
- **목표:** 밸런스를 브라우저 없이 검증한다.
- **산출물:** `tools/sim.ts`, 규칙 기반 봇 2종(신중형/공격형), `npm run sim` 스크립트.
- **완료 조건:** 봇별 1,000런을 실행해 승률, 평균 생존 밤, 패배 원인 분포, 평균 최대 열기를 콘솔 표로 출력한다(NFR-04).

### [ ] T-21 저장·불러오기
- **산출물:** `src/save/` (런 저장, 유산 저장 분리, 스키마 버전, 마이그레이션 훅).
- **완료 조건:** 저장 → 불러오기 후 다음 밤 결과가 저장 전 진행과 동일하다는 테스트가 통과한다(NFR-02, NFR-05, FR-LEG-03).

## M2. 화면

공통 완료 조건: 모든 문자열은 `src/i18n/ko.ts`에서 가져오고, 색은 팔레트 토큰만 쓰며, 씬이 상태를 직접 수정하지 않는다.

### [ ] T-30 씬 구조와 네비게이션
- **완료 조건:** 타이틀 → 은신처 → 지도/조직원/결산 간 이동, 뒤로 가기, 키보드 단축키 기본 세트가 동작한다(FR-UI-01, NFR-06).

### [ ] T-31 단말기 UI 프레임
- **완료 조건:** 스캔라인 오버레이, 패널 테두리, 버튼·게이지·툴팁 컴포넌트가 `src/ui/`에 있고 모든 씬에서 재사용된다(FR-UI-08).

### [ ] T-32 도시 지도 + 배치
- **완료 조건:** 3층 6구역 표시, 소유자 색, 안개 처리, 조직원을 행동 슬롯에 배치·해제, 예상 열기 증가량 미리보기, "밤 시작" 버튼으로 T-13 호출(FR-UI-03, FR-MAP-02~04, FR-HEAT-02).

### [ ] T-33 밤 실행 연출 + 이벤트 카드
- **완료 조건:** 행동이 순차적으로 짧게 표시되고, 이벤트 발생 시 모달로 멈춰 선택을 받는다(FR-TURN-02, FR-UI-05).

### [ ] T-34 결산 리포트
- **완료 조건:** 행동별 성공 확률과 결과, 수입·지출, 열기 변화, 조직원 상태 변화가 한 화면에 표시된다(FR-UI-04, FR-ACT-03).

### [ ] T-35 은신처 허브
- **완료 조건:** 측면 뷰에 현재 조직원 수만큼 대기 스프라이트가 보이고, 창밖 레이어에 비 효과가 있다. 낮 단계의 영입·이식·건설 메뉴 진입점 역할을 한다(FR-UI-02).

### [ ] T-36 조직원 화면 + 성장 메뉴
- **완료 조건:** 목록/상세, 영입, 사이버웨어 이식(인간성 감소 경고 포함), 사업 건설·업그레이드가 동작한다(FR-UI-06, FR-TURN-01의 4단계).
